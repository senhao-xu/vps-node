# 仪表盘用户流量明细

## Goal

在仪表盘页面新增「用户流量」区块，展示每位用户的流量使用情况，并可展开查看该用户在每个节点上的流量明细；支持「今日 / 累计」时间范围切换。

## Requirements

- 仪表盘在现有统计卡片下方新增用户流量表格，列为：用户（用户名 + ID）、状态、上传、下载、合计、配额使用情况（已用 / 配额）。
- 每行可展开，展开后显示该用户在每个节点上的流量明细：节点名称、所属服务器、上传、下载、合计。
- 时间范围可切换：「今日」（UTC 0 点起，与现有「今日流量」卡片口径一致）与「累计」。
  - 今日：全部数据来自 `traffic_records`（`created_at >= 今日 0 点`）。
  - 累计：用户合计来自 `users.used_bytes`（与用户列表口径一致），节点明细来自 `traffic_records` 全部留存记录（受保留策略限制，属于已知口径差异）。
- 表格按合计流量降序排列；无流量的用户也展示（合计为 0），便于总览。
- 数据随仪表盘每 30 秒自动刷新；切换时间范围立即重新加载。
- 仅管理员可见（复用 `requireAdmin`），不改动 Agent API。
- 前端沿用现有设计 token 与组件风格（StatusBadge、formatBytes 等），不引入新依赖。

## Acceptance Criteria

- [ ] `GET /api/dashboard/user-traffic?range=today|total` 返回全部用户的流量合计与节点明细，未认证请求返回 401，非法 range 返回 400。
- [ ] 仪表盘展示用户流量表格，按合计降序，展开行显示节点明细（节点名 + 所属服务器 + 上传/下载/合计）。
- [ ] 「今日 / 累计」切换生效：今日口径与 traffic_records 当日数据一致；累计用户合计与 `users.used_bytes` 一致。
- [ ] 表格随仪表盘 30 秒自动刷新，切换范围时立即刷新。
- [ ] 后端 `go test ./...` 全绿（含新 handler 的测试）；前端 `typecheck` / `lint` / `build` 全绿。

## Notes

- 节点 = nodes 表（协议入口），明细同时展示所属服务器名，与 NodesPage 的「所属服务器」列保持一致。
